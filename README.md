# Cristian Portfolio Demo

Dark-luxury frontend restyle demo of [christian-daniel-jensen.com](https://christian-daniel-jensen.com).

Content is kept as published on the original site. This repo only changes presentation for demo/review.

## Preview locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## GitHub Pages

Enable Pages on the `main` branch (root). Site will publish at:

`https://loneness-4ever.github.io/Cristian-portfolio-demo/`
